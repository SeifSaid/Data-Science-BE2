# Recherche d'information dans la littérature scientifique

Projet du MOD 7.2 (Introduction à la science des données), Centrale Lyon.

Moteur de recherche qui, pour un article donné, retrouve parmi ~25 candidats les 5 articles qu'il cite.

## Contenu

| Fichier | Rôle |
|---|---|
| `analyse.ipynb` | notebook principal (partie à compléter) |
| `rapport/` | rapport et figures |
| `consignes/` | consignes du BE |
| `requirements.txt` | dépendances (Python 3.14) |

## Données

Placer `corpus.jsonl`, `queries.jsonl` et `valid.tsv` dans `data/` (ignoré par git).
