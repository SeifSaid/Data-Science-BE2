# Recherche d'information dans la littérature scientifique

MOD 7.2 (Introduction à la sciences des données), BE séances 4, 5, 6

**Enseignants :** Julien Velcin (CM, BE), Antoine Becquet (BE)

## Délimitation du travail

Groupes de 3 élèves (plus petits autorisés mais déconseillés).

Moteur de recherche qui, étant donnée une publication (requête), retourne les articles les plus proches sémantiquement. Pour chaque requête : 5 articles cités (exemples positifs) et environ 25 articles aléatoires (exemples négatifs). Il faut retourner les 5 citations et écarter les autres.

Une semaine supplémentaire après les 3 séances.

**Date limite de rendu : 17/12/26 au soir**

## Ce qui est attendu

Trois éléments :

1. Le code Python, ré-exécutable dans un autre environnement (a priori Python 3.14), avec les bibliothèques nécessaires (ex. `requirements.txt`).
2. Un rapport PDF de 5 à 8 pages : problème, choix et motivations, résultats. Présenter les différentes manières de représenter requêtes et candidats (avec une petite explication), les approches de classement, les résultats avec les métriques employées, une petite discussion et une conclusion.
3. Le dépôt des prédictions sur l'ensemble de test du challenge.

Le rapport est déposé sur Moodle (PDF, 5 à 8 pages). Le code doit être structuré et commenté ; le rendre via git (avec un README adapté, URL dans le rapport) ou en archive sans les données. Un notebook est possible s'il est succinct et très lisible.

Dépôt sur Moodle et sur le leaderboard de la compétition du groupe :
